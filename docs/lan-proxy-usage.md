## 4. 推荐怎么选

### `clean`
适合：
- 更稳定的 clean 出口
- 重要业务
- 需要尽量固定出口的场景

### `mmxz`
适合：
- 通用机场节点池
- 大多数普通流量
- 对出口稳定性要求没那么严格的场景

## 5. 如果要做“每 50 人一组，且节点隔离”

推荐做法不是用 `clean.batch001` 这种 account 分组，而是直接给每一组分配一个**固定节点池**。

也就是说：
- 第 1 组 50 人 → `clean01`
- 第 2 组 50 人 → `clean02`
- 第 3 组 50 人 → `clean03`
- 第 4 组 50 人 → `clean04`

如果是 mmxz：
- 第 1 组 50 人 → `mmxz01`
- 第 2 组 50 人 → `mmxz02`
- 第 3 组 50 人 → `mmxz03`
- 第 4 组 50 人 → `mmxz04`
- 后续继续顺延到 `mmxz05`、`mmxz06` ... `mmxz28`

这种做法的好处是：
- 每个组对应一个固定节点池
- 组和组不会混到同一个节点上
- 真正实现资源隔离
